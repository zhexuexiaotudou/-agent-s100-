# Demo Corpus License Policy

The Digua demo corpus accepts these asset classes:

- Project-owned synthetic documents and generated CI fixtures.
- Wikimedia Commons files with explicit public-domain, CC0, CC BY, or CC BY-SA
  metadata from the Commons API.
- Open Images records with official image IDs and source metadata.
- User-local files stored only in Personal demo roots and never committed.

The release package does not redistribute third-party media by default. It
includes recipes, download scripts, manifests, attribution files, and checksums.
