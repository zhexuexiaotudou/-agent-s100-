# 地瓜 AI-NAS 离线 UI 保留式改版（2026-07-16）

## 结论

本阶段只改造 `/ui` 的原生 HTML/CSS/JS 表现层，在 S100P 与 NAS 均不在线的条件下完成可视化、响应式、无障碍和离线状态验收。现有页面路由、API 调用、身份令牌、ACL、受控复制、回收站确认和中文业务文案继续保留；没有把管理工作台改成营销落地页，也没有修改 Python 服务端。

本阶段不声明 S100P、NAS、本地 Qwen、文件读写、相册索引、备份任务或实机权限链路已经通过。它们必须在设备恢复在线后按本文末尾清单重新验收。

## 改版前审计摘要

- `/ui` 默认进入文件页，首页的用户工作台价值被隐藏。
- 未登录时顶部仍显示“管理员”，侧栏固定显示 `1.28 TB / 2.00 TB` 和 `64%`，通知红点及绿色状态点也不是接口事实。
- 首页首屏优先展示技术状态卡，移动端需要滚动后才能看到常用任务。
- 11 个导航项处于同一层级，移动端底栏横向滚动后才能访问后续页面。
- 助手在回答前展示后处理动作和技术边界信息，文件页的图标与登录状态不统一。
- 占位文字、12px 状态标签和移动触控目标存在对比度或尺寸风险；没有暗色配色。

设计方向保持“本地 AI-NAS 用户工作台”，强调安静、可信、低认知负担。设计强度取中低装饰、紧凑但不拥挤的信息密度，以及清晰可见的操作层级。

## 已实现内容

### 用户任务与真实状态

- `/ui` 默认进入首页。
- 首页先显示欢迎信息和四个常用任务：AI 助手、文件、相册、备份同步。
- 技术状态与 Token 信息移入默认折叠的“系统状态与技术信息”。
- 未连接设备时明确显示“设备状态待连接”和“存储容量待连接”；容量存在时才根据接口返回的 `used_bytes` / `total_bytes` 计算进度。
- 未登录时顶部显示“登录”，不再假设当前用户是管理员；通知面板按当前身份和连接状态生成内容。

### 导航与响应式

- 桌面侧栏按“常用 / 内容 / 系统与记录”分组，所有原有页面仍可访问。
- 移动端固定保留首页、AI 助手、文件、相册四个主入口，第五个“更多”入口提供报告、Token、运行、备份同步、笔记、审计和设置。
- 当前页面使用 `aria-current="page"`；移动端 11 个页面均无页面级横向溢出。

### 助手、文件与相册

- 助手回答完成前不显示继续追问、提炼、思维导图和导出动作。
- 处理位置、隐私与工具信息默认折叠，回答后才显示真实处理摘要。
- 文件查看模式使用一致的 SVG 图标和 `role="tab"` / `aria-selected`，登录状态集中为一个登录卡片。
- 文档卡片继续使用现有回收站确认链路，不新增硬删除入口。
- 相册在未登录、加载或错误状态只显示一个主要状态卡，避免重复空状态；未登录时上传按钮不可用。

### 排版、色彩与无障碍

- 中文系统字体优先，统一间距、卡片、按钮和分段控件。
- 支持 `prefers-color-scheme: dark` 和 `prefers-reduced-motion: reduce`。
- 提高占位文字及成功/危险标签对比度；移动端可见交互目标至少为 `44 × 44 px`。
- 保留跳过链接、键盘焦点、中文语言声明和原有图片查看键盘操作。
- 移除可见的 emoji 图标、假容量、假通知点、技术字段名和长破折号占位符。

## 保护边界

- 未修改 `scripts/probes/ai_nas_operator_portal_server.py` 或任何 Python API / 权限实现。
- 未修改 API 路径、请求方法、认证令牌保存、ACL、受控复制五步链路或回收站确认链路。
- 未引入 React、Vue、Tailwind、Bootstrap 或新的前端运行时依赖。
- 主工作区中已有的服务端、模型、报告和实验改动没有被带入本分支。
- 本分支保留了主工作区当时已有的文件分类 UI 基线；对应分类/上传接口属于后续在线联调范围，本阶段不把离线 404/503 当成功证据。
- 与远端 `main` 比对，原有 57 个前端 API 路径全部保留；当前工作区基线额外包含 3 个文件分类接口（分类状态、执行分类、文档上传），没有删除原有 API 路径。

7. 验证助手本地问答、证据、处理位置、隐私摘要、后处理动作及云端边界。
8. 验证相册索引、上传、主分类与空状态；不得使用样例数据补齐真实结果。
9. 验证备份、报告、Token、运行、笔记、审计和设置页面的真实返回与错误状态。
