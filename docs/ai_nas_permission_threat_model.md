# AI-NAS Permission Threat Model

Date: 2026-06-23

## Non-Negotiable Rule

AI answers must never reveal file names, snippets, thumbnails, metadata, counts,
folder names, generated summaries, report links, embeddings, OCR text, or
derived labels outside the caller's permission scope.

This rule applies equally to Web UI, HTTP APIs, AI retrieval, generated
Markdown/JSON reports, thumbnails, background indexes, and future SMB/NFS/WebDAV
adapters.

## Current Evidence Boundary

The current local identity and ACL fixture passed:

- Goal 2: `ok_nas_acl_identity_gate`
- Ten-goal closure: `ok_ai_nas_ten_goal_s100p_closure_gate`

That proves the local AI-NAS ACL model works for the fixture. It does not prove
full parity with inherited POSIX ACLs, SMB ACLs, AD/LDAP groups, real NAS share
rules, or vendor-specific permission exceptions. Real permission parity needs a
separate gate.

## Principals

| Principal | Current meaning | Future real-NAS mapping |
| --- | --- | --- |
| Anonymous/no-auth caller | Backward-compatible public root/status endpoints only | Disabled by default except explicit public shares |
| Local AI-NAS user | User in the AI-NAS identity database | Mapped to NAS account, LDAP, AD, or SSO identity |
| Local AI-NAS group | Group in the AI-NAS identity database | Mapped to NAS group, AD group, POSIX group, or vendor group |
| Admin | Fixture admin with wildcard access | Must be separated into system admin, storage admin, and AI admin roles |
| Background worker | Indexer, thumbnailer, OCR worker, embedding worker | Service identity with read scope bounded by configured roots |
| External adapter | SMB/NFS/WebDAV/mobile/plugin adapter | Must provide caller identity and effective permission result |

## Protected Resources

| Resource | Leak examples | Required protection |
| --- | --- | --- |
| File path and file name | "invoice_2024.pdf exists" | Filter before retrieval and before final answer |
| File content and snippets | Text chunk, OCR output, transcript | Filter source set before LLM/tool context is assembled |
| Metadata | size, owner, timestamp, tags, EXIF GPS | Treat as content unless explicitly public |
| Thumbnails and previews | photo/video frame, PDF preview | Generate and serve only within caller scope |
| Embeddings and labels | face/person label, CLIP label, duplicate cluster | Never expose cluster membership across ACL boundaries |
| Reports | Markdown/JSON evidence packet | Store under scoped report root and redact inaccessible sources |
| Audit logs | user names, paths, failed access attempts | Admin-only with role-specific redaction |

## Enforcement Points

| Layer | Enforcement requirement |
| --- | --- |
| Web UI | Hide inaccessible modules, files, reports, previews, and action buttons. UI hiding is not the security boundary; API must recheck. |
| HTTP API | Authorize every list/read/search/summary/action endpoint from the caller token and effective ACL. |
| AI retrieval | Apply permission filter before query expansion, ranking, reranking, summarization, and citation formatting. |
| Tool calling | Tool schema must include `caller_id`, `request_id`, `scope_roots`, and `approval_state`; tools reject missing scope. |
| Report generation | Report writer receives only authorized source IDs and writes a permission manifest with every report. |
| Thumbnail/OCR workers | Workers may process configured roots but publish outputs only through ACL-filtered stores. |
| Embedding index | Embedding rows carry source ACL/version stamp; search filters by effective permission before returning matches. |
| Protocol adapters | SMB/NFS/WebDAV adapters are observers or source-of-truth mappers, not permission bypasses. |

## Threats And Mitigations

| Threat | Risk | Mitigation | Gate requirement |
| --- | --- | --- | --- |
| Cross-user search result leakage | User learns private file names or counts | Filter candidate IDs before ranking and before count summaries | Two-user fixture with same query and disjoint visible results |
| Summary leakage through LLM context | LLM receives private snippets then refuses too late | Enforce ACL before prompt assembly | Prompt-capture test proves private sources never enter context |
| Thumbnail leakage | UI shows private photo preview in mixed album | Thumbnail endpoint requires caller auth and source ACL | Per-user thumbnail request test |
| Duplicate cluster leakage | User sees private file is duplicate of visible file | Cluster output must include only visible members and avoid hidden-count hints | Duplicate fixture with hidden twin |
| OCR/EXIF metadata leakage | Private scanned text or GPS leaks through metadata search | Treat OCR/EXIF as content; filter like document text | OCR and EXIF scoped search test |
| Report link leakage | Report generated by admin reveals paths to non-admin | Reports carry owner/scope and are reauthorized on read | Report read denied across users |
| Background index drift | ACL changed but stale index still exposes old rows | ACL version stamp and revalidation at read time | Change ACL after indexing and rerun query |
| Admin overreach in demo | All admins are treated as storage superusers | Role split and explicit privileged mode | Admin role matrix test |
| Protocol mismatch | SMB says denied but AI-NAS allows through local ACL | Real NAS adapter effective permission wins | Real ACL mapping gate |

## Required Real ACL Mapping Gate

Add a future gate named `ai_nas_real_acl_mapping_gate` before claiming
permission-complete multi-user NAS parity.

Minimum gate cases:

- Create or select at least three real NAS users: admin, editor, viewer.
- Map at least two real NAS groups, including inherited group membership.
- Use at least four roots: public, editor-only, viewer-only, admin-only.
- Include at least one inherited permission and one explicit deny.
- Verify file listing, document search, folder Q&A, photo search, thumbnails,
  OCR search, report read, and action proposal for each principal.
- Change one ACL after indexing and prove the next query respects the new
  permission without requiring a full reindex.
- Prove hidden files do not affect visible counts, summaries, labels, or
  citations.
- Save JSON/Markdown evidence with the effective permission decision for every
  returned source.

Expected verdict:

```text
ok_ai_nas_real_acl_mapping_gate
```

## Review Rule

No new AI-facing feature may be marked complete until it answers this question:

> What happens when two users ask the same question and only one of them can
> see the relevant file?

If the answer is not covered by a test or gate, the feature remains prototype
scope.
