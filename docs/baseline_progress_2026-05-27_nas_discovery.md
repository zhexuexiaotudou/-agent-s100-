## Implementation

NAS discovery reports are generated by:

```text
scripts/probes/nas_discovery_probe.sh
```

The allowlist runner exposes it as:

```bash
scripts/run_allowlisted_tool.sh nas_discovery_probe /root/.openclaw/workspace/logs/probes
```

OpenClaw exposes the same read-only path through:

```json
{"tool_id":"nas_discovery_probe"}
```
