# Open Visual Corpus License Policy

Allowed sources are Wikimedia Commons files with explicit Commons metadata,
Open Images records supplied through a reviewed seed CSV, project-owned
synthetic documents, and user-local media stored only under Personal demo roots.

Every manifest record must include source URL, source ID, license, author,
attribution, SHA256, modality, expected categories, and release-bundling policy.
Third-party records default to `release_package_includes_manifest_only=true`.

Forbidden inputs include search-engine downloads without license metadata,
private receipts/contracts, face-identity datasets, age/gender/race/emotion
datasets, and any third-party image redistributed as project-owned data.
