This note records the first operator-approved named ROS bag capture under the
A-009 capture policy. It is separate from the shorter start/status/stop
self-test and from the read-only capture-policy probe.

## New Probe

```text
script: scripts/probes/rosbag_named_capture_probe.sh
tool_id: rosbag_named_capture_probe
mode: bounded-capture
default dataset root: /mnt/nas/openclaw/robot_datasets
default report root: /mnt/nas/openclaw/logs/probes
default duration: 300 seconds

```

Safety boundary:

- The session name is generated by the script as
  `approved_named_capture_YYYYmmdd-HHMMSS`.
- The operator approval is recorded as `chat_approved_2026-05-28`.
- The script records only approved low-risk status topics that currently exist:
  `/rosout`, `/parameter_events`, `/tf`, `/tf_static`, `/joint_states`,
  `/diagnostics`.
- The script never sends robot motion or control commands.
- Duration is bounded by `ROSBAG_NAMED_CAPTURE_SECONDS` and capped at 1800
  seconds.
