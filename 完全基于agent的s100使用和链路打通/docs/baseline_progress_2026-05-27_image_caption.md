## Implementation

Image caption indexes are generated by:

```text
scripts/probes/image_caption_probe.sh
```

The allowlist runner exposes it as:

```bash
scripts/run_allowlisted_tool.sh image_caption_probe \
  /root/.openclaw/workspace/photos \
  /root/.openclaw/workspace/reports/image-captions
```

OpenClaw exposes the same read-only path through:

```json
{"tool_id":"image_caption_probe"}
```

## Current B-003 Verdict

B-003 has a verified local workspace fallback through both the allowlist runner
and the narrow OpenClaw plugin.

This is intentionally a metadata-caption baseline. It makes photos searchable by
path, filename-derived caption, dimensions, size, and hash. It does not yet
prove semantic visual captioning.
