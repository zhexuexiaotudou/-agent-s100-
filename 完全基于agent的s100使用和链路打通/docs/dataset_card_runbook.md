# Dataset Card Runbook

This runbook supports B-004: robot dataset cards.

## Goal

Every robot data capture should write a small Markdown card beside the dataset so future agents can understand what was captured without opening large files.

For the first baseline, dataset cards are generated by:

```text
scripts/probes/rosbag_snapshot_probe.sh
```

## Output

For each bounded ROS bag snapshot:

```text
robot_datasets/
  rosbag_snapshot_YYYYmmdd-HHMMSS/
    DATASET_CARD.md
    metadata.yaml
    *.db3
```

## Card Fields

`DATASET_CARD.md` includes:

- Capture type.
- Dataset ID.
- Bag directory.
- Duration.
- Topics.
- Metadata presence.
- Verdict.
- Safety boundary.
- File list and sizes.
- Available ROS topics at capture.
- `ros2 bag info` output.
- Reproduce command.

## Acceptance

Local fallback is verified when a capture produces:

```text
DATASET_CARD.md
metadata.yaml
*.db3
```

and the card contains:

```text
capture_type: bounded_rosbag_snapshot
topics: /rosout /parameter_events
metadata_exists: yes
verdict: ok
```

NAS-backed acceptance still requires the same card under:

```text
/mnt/nas/openclaw/robot_datasets/<dataset_id>/DATASET_CARD.md
```
