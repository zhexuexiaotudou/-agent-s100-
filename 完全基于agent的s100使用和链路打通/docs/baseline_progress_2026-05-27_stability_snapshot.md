## Implementation

Stability snapshots are generated by:

```text
scripts/probes/stability_snapshot_probe.sh
```

The allowlist runner exposes it as:

```bash
scripts/run_allowlisted_tool.sh stability_snapshot_probe /root/.openclaw/workspace/logs/probes
```

Scheduled collection is managed by:

```bash
scripts/install_stability_sampler.sh plan
scripts/install_stability_sampler.sh install
scripts/install_stability_sampler.sh status
scripts/install_stability_sampler.sh uninstall
```

The sampler installs:

```text
openclaw-stability-sampler.service
openclaw-stability-sampler.timer
```

Default interval:

```text
1800 seconds
```

The installer is intentionally outside the OpenClaw conversation allowlist
because installing or removing systemd units is an operator-level action.

Collected snapshots are summarized by:

```bash
scripts/run_allowlisted_tool.sh stability_summary_probe \
  /root/.openclaw/workspace/logs/probes \
  /root/.openclaw/workspace/reports/stability
```

OpenClaw exposes the same read-only summary path through:

```json
{"tool_id":"stability_summary_probe"}
```
